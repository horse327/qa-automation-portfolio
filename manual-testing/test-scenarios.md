# Test Scenarios

## Feature: User Login

### TS-LOGIN-001 — Login with valid credentials
Verify that a registered user can successfully log in using a valid username/email and password.

### TS-LOGIN-002 — Login with invalid password
Verify that the system displays an appropriate error message when the user enters an incorrect password.

### TS-LOGIN-003 — Login with empty fields
Verify that validation messages are displayed when required fields are left empty.

### TS-LOGIN-004 — Login with unregistered email
Verify that the system prevents login and shows an error message for unregistered users.
