# Bug Reports

This folder contains examples of bug reports written using professional QA practices.

## Contents
- **bug-report-template.md**  
  A generic bug report template demonstrating standard structure and terminology.

- **orangehrm-shortlist-500.md**  
  A real, high-impact defect identified in the OrangeHRM open-source project, including:
  - Clear reproduction steps
  - Business and operational impact analysis
  - Backend API validation (HTTP 500 error)
  - Supporting screenshots and technical evidence

These reports reflect real-world QA responsibilities rather than hypothetical examples.
